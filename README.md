# Retired: evidence-validation-identity

This separate identity service is no longer needed. Evidence Validation now uses **Astra Lab's existing Supabase project and accounts**.

The identity deployment workflow, runtime code, database migrations, and container definitions have been removed. Its Google VM, disk/backups, dedicated secrets, routing, certificate, firewall rules, and service identities have been removed.

Continue development in [evidence-validation](https://github.com/Astra-via-Omer/evidence-validation). No second authentication service or identity hostname is required. This repository is archived for history only.
